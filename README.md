# Wikipedia-Search-Application

## 📖 Project Overview

The **Wikipedia Search Application** is a mini web project developed as part of the **NxtWave Dynamic Web Applications Learning Program**. This application allows users to search Wikipedia articles by entering a keyword and pressing Enter. The search results are fetched dynamically using an API and displayed with the article title, URL, and a brief description.

## 🚀 Features

* Search Wikipedia articles in real-time
* Fetch data using JavaScript Fetch API
* Display article title, link, and description
* Loading spinner while fetching results
* Responsive user interface using Bootstrap
* Opens selected articles in a new browser tab

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Bootstrap 4
* Fetch API

## ⚙️ How It Works

1. User enters a keyword in the search box.
2. Presses **Enter** to initiate the search.
3. The application sends a GET request to the Wikipedia Search API.
4. A loading spinner is displayed while data is being fetched.
5. Search results are dynamically rendered on the webpage.
6. Users can click any result to open the corresponding Wikipedia article.
